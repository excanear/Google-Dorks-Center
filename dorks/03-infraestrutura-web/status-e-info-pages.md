## 🎯 Curados

### Status de servidor web

| Dork | Finalidade | Buscadores | Risco |
|---|---|---|---|
| `inurl:/server-status "Apache Server Status"` | mod_status do Apache | Google | 🟡 |
| `inurl:/server-info "Apache Server Information"` | mod_info do Apache | Google | 🟡 |
| `inurl:/nginx_status "Active connections"` | stub_status do Nginx | Google | 🟡 |

### Métricas e health de aplicação

| Dork | Finalidade | Buscadores | Risco |
|---|---|---|---|
| `inurl:/actuator/health "status":"UP"` | Spring Boot Actuator | Google | 🟡 |
| `inurl:/actuator/env` | Actuator expondo variáveis de ambiente | Google | 🔴 |
| `inurl:/actuator "_links"` | Índice de endpoints Actuator | Google | 🟡 |
| `inurl:/metrics "# HELP"` | Métricas no formato Prometheus | Google | 🟡 |
| `inurl:/debug/vars intext:"cmdline"` | expvar do Go | Google | 🟡 |
| `inurl:/status.php "uptime"` | Status genérico de app | Google | 🟡 |
| `inurl:/health "database" "ok"` | Health check com dependências | Google | 🟡 |

## 🔁 Traduções entre buscadores

| Google | Bing | Shodan | FOFA |
|---|---|---|---|
| `inurl:/server-status "Apache Server Status"` | `instreamset:url:/server-status` | `http.title:"Apache Status"` | `body="Apache Server Status"` |
| `inurl:/actuator/env` | `instreamset:url:/actuator/env` | `http.html:"/actuator/env"` | `body="/actuator/env"` |

## 📝 Notas & falsos positivos

- `/actuator/env`, `/actuator/heapdump` e introspecção **GraphQL** são 🔴: vazam config e, no caso de heapdump, memória com segredos.
- `security.txt` e `swagger` são recon legítimo e geralmente intencionais.
- `server-status`/`nginx_status` só respondem quando mal configurados para acesso externo.
- Endpoints Prometheus (`/metrics`) revelam nomes de hosts, jobs e topologia — útil para mapear a stack.
