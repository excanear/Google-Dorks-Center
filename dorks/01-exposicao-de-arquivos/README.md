## 🧭 Como usar esta categoria

1. Comece por **[Diretórios Abertos](diretorios-abertos.md)** — uma listagem aberta costuma concentrar vários dos achados abaixo.
2. Restrinja ao **escopo autorizado** com `site:alvo.com` em qualquer dork.
3. Reduza ruído com as exclusões sugeridas em cada página (`-template -sample -example`).
4. Para registrar a evidência sem baixar o corpo, use o [Wayback Machine](https://web.archive.org/).
