## 🧭 Como usar esta categoria

1. **Arquivos geoespaciais** revelam territórios, ativos e rotas mapeados por uma organização.
2. **Servidores de mapa** (GeoServer/ArcGIS) expõem camadas internas — às vezes dados que não deveriam ser públicos.
3. **Rastreamento de frota** é o mais sensível: localização em tempo real de veículos e, por tabela, de pessoas.
