## 🧭 Como usar esta categoria

1. Use o fingerprint para **confirmar a stack** antes de aprofundar o recon.
2. Cruze versão identificada com bases de CVE — mas a exploração fica fora daqui.
3. Para varredura em escala, Shodan/Censys/FOFA superam buscadores web (veja as traduções e o [manual de infraestrutura](../../docs/manual/03-buscadores-de-infraestrutura.md)).
